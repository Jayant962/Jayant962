## 🧠 About Me

I’m a Data Science student focused on building end-to-end, real-world solutions—from data preprocessing and analysis to model development, evaluation, and deployment.

My work spans across multiple domains including Machine Learning, Deep Learning, and Natural Language Processing (NLP) using Hugging Face, along with strong capabilities in Data Analytics using SQL, Excel and business intelligence tools.

Beyond data science, I also work with DevOps and cloud technologies such as Docker, Kubernetes, and CI/CD pipelines. I have a solid foundation in core computer science concepts like DSA, OOP, and operating systems.

I aim to build projects that reflect real industry use cases and align with roles such as Data Scientist, Machine Learning Engineer, NLP Engineer, and Software Developer.
